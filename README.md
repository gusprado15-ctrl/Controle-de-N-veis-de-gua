# Controle de Níveis de Água

Este projeto foi feito em Python para simular o monitoramento do nível de água de um reservatório.

O programa utiliza uma lista para guardar os níveis de água e uma função para definir a cor de cada mensagem.

Foi utilizada a biblioteca Colorama para mostrar as mensagens coloridas no terminal.

## Tecnologias utilizadas

- Python
- Biblioteca Colorama

## Como executar

1. Instale a biblioteca com `pip install colorama`.
2. Execute o arquivo com `python app.py`.
